## 專案簡介 (Project Overview)
**SmartFit** 是一款針對健身愛好者與體重管理族群打造的 Web 工具。透過輸入個人身體數據（身高、體重、體脂率、運動頻率），自動計算出基礎代謝率 (BMR)、每日總消耗熱量 (TDEE) 以及精確的增肌/減脂蛋白質、碳水化合物、脂肪攝取比例。

---

## 核心價值 (Value Proposition)

### 1. 使用價值 (Usage Value)
* **高頻剛性需求：** 現代人越來越注重體態管理與增肌減脂，精確的熱量與巨量營養素 (Macros) 計算是健身成功的關鍵。
* **極簡直覺操作：** 免去繁瑣的手算公式，提供一鍵生成每日餐單熱量與營養素分配建議。

### 2. 商業價值 (Commercial Value)
* **訂閱制 / 健身房合作 (SaaS / B2B)：** 可與線上健身教練、健身房或餐盒訂閱服務 (Meal Prep) 結合，作為顧客體態追蹤與專屬菜單推薦系統。
* **個人化客製擴充：** 未來可串接 AI (如 OpenAI / Gemini API)，根據個人飲食偏好（高蛋白、低碳水、素食等）自動生成一週採買清單與食譜。

---

## 功能特色 (Features)
1. **BMR & TDEE 精確試算：** 採用 Mifflin-St Jeor 公式計算。
2. **目標熱量規劃：** 支持「維持體重」、「增肌 (Bulking)」與「減脂 (Cutting)」三種目標。
3. **巨量營養素拆解：** 自動分配每日所需的 **蛋白質 (g)**、**碳水化合物 (g)** 與 **脂肪 (g)**。
4. **輕量化 Web 介面：** 基於 Python FastAPI 構建，響應迅速且易於維護。
